# Invoera for Windows

Create, send and track professional invoices on your computer. Sign in with the same account as the Android app and your invoices stay in sync.

**Download:** [Invoera-Setup.exe](https://github.com/aniezesidney6-source/invoera-windows/releases/latest/download/Invoera-Setup.exe) (Windows 10 or 11, 64-bit)

If Windows shows a SmartScreen notice, choose **More info**, then **Run anyway**.

Website: https://pay-invoera.vercel.app · Android: https://play.google.com/store/apps/details?id=com.icedpixels.invoera
